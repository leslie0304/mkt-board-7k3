- **事件**：量子算法初创公司**上海伏曦量子科技有限公司**宣布连续完成天使及天使+轮融资。领投方为全球动力电池龙头**宁德时代**，**小苗朗程**、五源资本、德迅投资等跟投。

  - 优先级：**中**
- **来源**：[MSN/C114](https://www.msn.cn/zh-cn/news)（6月24日）

### 2.2 基金动态

#### 浦东智能智造二期基金募集完毕 ⭐⭐

- **事件**：**上海浦东智能智造二期私募投资基金合伙企业（有限合伙）**已于2026年6月募集完毕。该基金由**上海金桥投资合伙企业（有限合伙）**作为有限合伙人参与出资设立，而上海金桥投资合伙企业的执行事务合伙人为**盛讯投资**（人脉资源库2级合作机构，联系人：雷卫红，投资总监）。
- **值得关注的原因**：
  - **盛讯投资穿透两层**：盛讯投资 → 金桥投资合伙 → 浦东智能智造二期基金 → （即将对外投资企业）
  - 该基金聚焦智能制造赛道，与我们关注的集成电路、具身智能方向高度吻合
  - 基金已募集完毕，预计近期将开始对外投资，被投企业将是潜在客户
- **营销机会**：
  - 密切关注该基金的对外投资动向，第一时间对接被投企业
  - 可通过盛讯投资的雷卫红获取基金拟投项目清单
  - 产品切入点：科创贷（被投企业）、托管/监管（基金层面）、投贷联动
  - 优先级：**高**
- **来源**：[中国证券报](https://paper.cnstock.com/html/2026-06/26/content_2235486.htm)（6月26日）
