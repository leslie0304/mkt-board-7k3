## 展会基本信息

2026年**10月12日至16日**，中国工博会集成电路展（"国芯展"）将在**国家会展中心（上海）**举行。

本届"国芯展"是工博会首次独立打造的集成电路专业展：

| 项目 | 内容 |
|---|---|
| 展会面积 | 超 3 万平方米 |
| 主办 | 东浩兰生（集团）有限公司 |
| 承办 | 上海市集成电路行业协会、东浩兰生会展集团上海工业商务展览有限公司、上海现代企业经营管理研究会 |
| 核心理念 | 自主可控·链通全球·产融协同·应用落地 |

## 一、首次以"整体形象"组团参展，展位规模居首

金桥装备小镇采取"统一规划、统一租赁、统一布展"方式：

- 展区总面积 **495 平方米**，为**本届展会规模最大的参展单位**
- 展区划分为：小镇展示区 + 设备、零部件、功能性平台及材料**四大板块**
- **28 家**装备小镇内企业确定参展

### 参展企业名单（28 家）

| 类别 | 企业 |
|---|---|
| 设备 | 华海、中微、凯世通、御微、精智达、埃芯、卓垣、Ebara |
| 零部件 | 隐冠、恒运昌、道格特、星奇、复享光学、左麟、弗莱曼、视光微、沈科仪、联合光科、沸点、励兆、复矽源 |
| 功能性平台及材料 | 爱芯享、咖瑟孚、泓明、上理工、安集、天承 |

## 二、专业论坛同步举办，聚焦设备零部件生态集聚

- **时间**：10月13日上午
- **地点**：国家会展中心 5.2H 分论坛A
- **主题**："半导体设备、零部件生态集聚与协同创新"
- **联合主办**：复旦大学校友总会集成电路行业分会、复旦MBA半导体商业与生态俱乐部、中欧上海校友会电子半导体协会、上海交通大学安泰MBA泛半导体专委会
- **拟邀嘉宾**：中芯国际联合创始人**谢志峰博士**等
- **形式**：嘉宾演讲 + FAB、装备、零部件、材料、投资机构、政府园区及 APM 代表圆桌讨论
- 同步开展装备小镇及**爱芯享供应链平台**专题推介

## 三、金桥装备小镇：锻造硬核智造"新地标"

- 金桥是上海集成电路产业重要发源地，源头可追溯至国家"**909**"工程——华虹集团在此成立，建成中国大陆第一条 8 英寸芯片生产线
- 金桥装备小镇 **2026年1月正式揭牌**，是浦东构建现代化产业体系、培育新质生产力的重要落子
- **空间布局**：依托金桥南区金谷智能终端特色产业园，规划面积约 **4 平方公里**、拓展至 **7 平方公里**
- **产业格局**：构建"**2+X+3**"产业体系
  - 做强两大装备产业链：光学、先进存储
  - 聚焦核心设备：先进封装、薄膜沉积、量检测
  - 关键零部件赛道：光学、真空、电控、精密运动、流体
- 已建成**集创园、集光园、集核园**等专业园区，配套高标准厂房、研发办公和人才公寓
