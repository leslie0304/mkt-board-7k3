## 一、集成电路 / 半导体

1. SK海力士联手闪迪发布 HBF 首个开放标准规范，谷歌、Tenstorrent 加入联盟

事件内容：8月4日 FMS 2026 闪存峰会开幕当天，SK海力士与闪迪共同发布下一代存储技术高带宽闪存（HBF）的首个标准规范，由 OCP 正式发布为行业通用开放标准。规范定义 8 层与 16 层 NAND 堆叠两种配置、最高 512GB 容量，按三个等级设定 0.4TB/s 至 3.0TB/s 带宽，并采用 UCIe 与 GPU/CPU 互联。谷歌、Tenstorrent 已加入 HBF 联盟，SK海力士同期首展第十代 375 层 4D NAND。

值得关注的原因：HBF 是介于 HBM 与 SSD 之间的全新存储层级，直接冲击 AI 推理时代的"内存墙"瓶颈。标准以开放形态落地意味着国内存储、封装、接口 IP 厂商有机会切入生态，而非被单一厂商锁死，对区内存储接口芯片、先进封装、测试企业构成中期订单预期。

信息来源：[SK海力士官方新闻室（8月4日）](https://news.skhynix.com/cn/hbf-at-fms-2026/)

营销机会：可梳理区内 UCIe 接口 IP、存储主控、先进封装测试企业名单，围绕"HBF 生态卡位"做技术路线沟通，提前储备设备采购贷、研发贷与并购顾问需求。

值得关注的原因：这轮存储景气由 AI 驱动，与以往消费电子主导的周期存在本质区别——供给端提前一年锁定，意味着 2027 年之前存储成本对下游硬件厂商是刚性上涨压力。对银行而言，一端是存储产业链客户的扩产融资窗口，另一端是消费电子、面板、模组类客户的成本挤压与还款能力预警。

信息来源：[腾讯新闻综合报道（8月4日）](https://new.qq.com/rain/a/20260804A0AJOJ00) + [TechSugar 每日头条芯闻（8月4日）](https://www.163.com/dy/article/L3FN2RM805312NX9.html)

营销机会：对存储产业链客户主推产能扩张类项目贷、设备融资租赁；对下游成本承压客户提前做授信复审与流动性方案，并可切入远期结售汇、大宗价格锁定等避险产品。
