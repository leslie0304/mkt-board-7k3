## 核心观点

当国产半导体整机设备成功搬入晶圆厂产线，产业链焦虑重心从"能不能造出整机"转向"能不能长期稳定生产、持续无宕机交付"。决定这一命题的是机台内部成千上万的基础部件。**半导体设备国产化的下半场，实质是一场零部件的韧性之战。**

## 一、行业定义：工艺配方的物理载体

半导体设备零部件指安装在晶圆制造、先进封装及厂务动力系统内部，用以实现特定物理与化学反应的基础功能单元。并非通用工业零件，而是**半导体制造工艺配方的物理载体**。

工作环境极端：强腐蚀性气体、高能等离子体轰击、高真空、剧烈冷热交替循环。核心功能涵盖真空建立、超高纯气体输送、等离子体激发与控制、晶圆纳米级传输、毫秒级精密温控、超高精度光学测量。

## 二、行业分类：五大核心零部件及价值占比

| 类别 | 占设备总成本 | 主要构成 |
|---|---|---|
| 机械类零部件 | 20%–40% | 铝合金/不锈钢反应腔体、喷淋头、衬套；石英件、特种陶瓷件、硅环、静电卡盘 |
| 气体/液体/真空系统 | 10%–30% | 干式真空泵、分子泵、高气密真空阀门、气柜、超高纯管道、气体过滤器与进气系统 |
| 电气与电源系统 | 10%–20% | 射频电源、射频匹配器、远程等离子体源（RPS）、高压供电模块 |
| 机电一体与传输系统 | 10%–25% | 晶圆传输机械手（Robot）、EFEM、双工件台、微环境控制、精密温控单元 |
| 仪器仪表与光学类 | 常规设备 1%–3%；光刻/量测设备高达 55% | MFC、真空压力计、高精度激光源、光学物镜组 |

## 三、本土发展历程：三阶段递进

1. **第一阶段：基础结构件突破**——金属腔体、结构支架、通用管路，依靠国内成熟精密加工能力率先本土化。
2. **第二阶段：工艺耗材与常规部件替代**——石英件、部分硅环、普通密封圈、基础真空泵进入本土整机厂采购清单。
3. **第三阶段：核心功能子系统联合攻坚（当前深水区）**——射频电源、MFC、静电卡盘、超高精度机械手。供应链从买卖关系转为**深度联合研发**。

## 四、产业链特征：高壁垒与不对称价值

呈现"**上游材料突破难、中游工艺验证长、下游更换成本极高**"结构。整机厂掌握架构与客户入口、占据最大名义产值，但**技术咽喉**掌控在核心子系统企业手中。一旦通过验证并写入整机工艺配方，下游客户几乎不会更换供应商。

## 五、上中下游深度解析

**上游——特种原材料与表面工程**：超高纯度铝合金、特种不锈钢、高纯石英、碳化硅陶瓷、高纯氧化铝陶瓷、氟橡胶、特种电子元器件。难点在于材料提纯冶炼以消除微观缺陷与杂质；表面工程（精密阳极氧化、PVD/CVD涂层、超高洁净清洗）决定零部件是否会释放颗粒或金属离子污染。

**中游——精密制造与多品种小批量**：特征是**多品种、小批量、高定制化**，难靠单一标准品形成规模效应；核心竞争力是制造工艺的一致性与收得率（如射频电源需融合电力电子、电磁学、控制算法与等离子体物理，逆向工程无法复制）。

**下游——苛刻验证与极高黏性**：商业化需过三关——零部件厂内部极限测试 → 整机厂研发机腔体匹配与工艺调试 → 随整机进晶圆厂接受数月至一年以上真实工艺测试。考核指标含金属污染物沉淀、颗粒掉落、MTBF、批次一致性。劣质零部件导致停机的损失远高于其采购成本，形成极强黏性与进入壁垒。

## 结论与待观察问题

上半场解决整机从"无"到"有"；下半场胜负取决于零部件能否实现"**稳定、持续、可重复**"的规模化交付。国内企业需从"照图加工"代工模式转向与整机厂共同定义架构、共同开发底层技术。

> 待观察：在先进封装、HBM、更高端制程不断推高设备复杂度的背景下，本土零部件供应链的迭代速度，能否赶在海外技术生态再次演进之前筑牢产业底座。
