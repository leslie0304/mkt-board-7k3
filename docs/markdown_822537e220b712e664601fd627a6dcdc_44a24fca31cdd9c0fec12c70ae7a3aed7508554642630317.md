### 二、芯片设计与先进封装

**8. 华为首披露麒麟 9050「逻辑折叠」量产细节：不拼光刻机，拼 3D 架构**（10/13）

- **来源**：科技日报 / 澎湃 / 光明网 / 第一财经（全文核验）；主通道多篇（想念之旅 / 生产队的骡子 / 落花 python 记）交叉印证
- **事件**：10/13 华为在上海练秋湖研发中心举行麒麟芯片技术沟通会（时隔六年首次），半导体业务无线终端芯片产品管理部部长徐松余公布首款逻辑折叠（韬定律 τ scaling）芯片**麒麟 9050 系列架构图**：
  - **晶体管密度 +53.5%**；混合键合数量超 **5000 万**、有效信号互连超 500 万；**混合键合间距 1.5μm**，计划 2027 年缩小至 1μm 并探索更多层折叠
  - 麒麟 9050 Pro：CPU 多核性能 +23%、大核能效 +41%、新一代达芬奇 NPU 性能 +140% / 功耗 -66%；端侧可流畅运行 30B MoE 大模型（新增占用 2.5GB 内存）、加载性能 +25%、较上代省 75% 内存占用
  - 2027 年麒麟样片已在测试；2023 年以来麒麟终端累计发货超 1 亿部
- **产业落点**：逻辑折叠把多颗 DIE 作为一颗完整芯片协同设计，直接拉动**混合键合、TCB、晶圆级封装、Retimer、EDA**环节——本报 10/07—10/08 跟踪的「混合键合价值链重估」（ASML 进军、Besi 被下调、应材 × Besi EPIC 合攻 D2W）再获终端需求侧印证。
