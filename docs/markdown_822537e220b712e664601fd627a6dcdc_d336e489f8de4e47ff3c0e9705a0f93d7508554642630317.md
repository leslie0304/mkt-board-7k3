3. 中国禁止氦气出口，全球半导体供应链面临结构性冲击

事件内容：据半导体行业观察7月14日报道（ETIS微鉴/头条转载），中国商务部和海关总署于7月10日联合发布公告，即日起对氦气实施临时禁止出口管理，无缓冲期、无豁免名单。氦气是全球半导体制造的战略性不可替代物资——用于晶圆冷却、离子注入环境净化、EUV光刻机光学元件运行。中国自身95%依赖进口，是全球最大消费国。导火索为今年3月伊朗无人机袭击卡塔尔拉斯拉凡LNG生产基地（供应全球30–35%氦气），修复需3–5年，意味着全球氦气市场面临多年结构性短缺。消息一出，日韩芯片巨头连夜开会，美国半导体协会紧急发声。

值得关注的原因：氦气禁运将从成本端倒逼国内晶圆厂加速国产替代与工艺优化，同时推高芯片制造成本，可能引发新一轮半导体设备与材料投资热潮。上海作为全国晶圆制造最集中城市之一，相关企业影响直接。

信息来源：[半导体行业观察](https://www.toutiao.com/article/7662257751933862454/)（Part1：jintiankansha.com，4小时前更新）
