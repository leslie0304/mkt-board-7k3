# 半导体设备六大核心零部件全解析

## 背景

AI算力紧缺背景下，全球半导体资本开支进入新一轮上行周期。美光、三星、SK海力士、铠侠等海外存储巨头相继上调中长期扩产规划，投资从现有产线延伸至新建晶圆厂，多数长期布局延续至2030年后。设备端扩产需求正加速向零部件环节传导。

## 一、行业概览：六大类零部件与价值占比

| 类别 | 占零部件总价值 | 国产化进展 |
|---|---|---|
| 机械类 | 20%–40% | 推进较快，已实现一定规模国产替代 |
| 电气类（射频电源等） | 10%–20% | 高端仍高度依赖海外，替代空间广阔 |
| 机电一体类 | 10%–25% | 部分突破 |
| 气体/液体/真空系统类 | 10%–30% | 推进较快 |
| 仪器仪表类 | — | 技术难度大，替代空间广阔 |
| 光学类 | — | 高精度光学元件依赖海外 |

特征：工艺精度要求高、**多品种小批量**，覆盖数十个细分技术领域，是半导体制造中高壁垒的"卡脖子"环节。增长核心驱动已转向 AI服务器、HBM、先进逻辑制程、先进封装与异构集成共同催生的新一轮扩产。

## 二、产业链上下游

**上游（材料）**
- 硅片：12英寸高端长期由海外主导；国内成熟尺寸稳定量产，28nm及以上制程配套硅片国产化率已突破30%。
- 光刻胶：低端 g/i 线国产化最快，头部厂商本土晶圆厂导入率超90%；高端 ArF 已进入12英寸晶圆厂中试线批量验证，部分产品通过14nm认证。
- 电子特气：多款常规工艺气体导入头部晶圆厂；氪气、氖气等已大规模自主量产。
- 掩模：成熟制程稳定供货；28nm以上先进制程掩模进口依赖度仍超60%，头部企业已启动7nm攻关。

**中游（零部件制造）**
- 金属加工件等低难度领域国产化率已突破50%。
- 射频电源、高精度真空阀、EUV光学系统等高端件要求纳米级精度，壁垒与供应链安全风险并存。
- **2026年全球半导体制造设备销售额预计165.9亿美元，同比+23.2%，创历史新高**，直接带动精密零部件订单攀升。

**下游**
覆盖设备制造商、晶圆制造厂及终端应用，形成"零部件—设备—晶圆制造—终端应用"闭环。据Gartner，典型产线设备投资中光刻机、刻蚀机、薄膜沉积、离子注入、测试、清洗合计占比超80%。国内头部存储厂商扩产聚焦12英寸先进制程设备，带动高层数刻蚀和薄膜沉积设备零部件需求快速增长。

## 三、竞争格局

整体市场分散但**细分领域垄断显著**：全行业集中度约50%，细分品类集中度普遍达80%–90%。据VLSI Research，近十年全球前十大关键子系统供应商市占率稳定在约50%。

**全球前十领军供应商**：蔡司ZEISS（光学镜头）、MKS万机仪器（MFC、射频电源、真空产品）、Edwards爱德华（真空泵）、Advanced Energy（射频电源）、Horiba堀场（MFC）、VAT徽拓（真空阀件）、Ichor（模块化气体输送系统）、Ultra Clean Tech超科林（密封系统）、ASML（光学部件）、EBARA荏原（干泵）。

## 四、六大环节国内企业地图

**机械类**
- 金属腔体与工艺组件：富创精密（国内少数进入国际设备厂商供应链的内资企业）、华亚智能（刻蚀控制、晶圆检测）、菲利华（石英腔体，光刻机光源核心部件）、靖江先锋、托伦斯精密（腔体、法兰、连接件）。
- 结构件：神工股份（硅零部件，供国内刻蚀机原厂及存储/逻辑Fab）、晶盛机电（高纯石英坩埚、半导体阀门管件）、江丰电子（高纯溅射靶材龙头，宁波余姚/上海奉贤/沈阳沈北三大基地）。

**机电一体类**
- 腔体模组&阀体模组：富创精密（可提供实现部分设备核心功能的模组）。
- 双工件台：华卓精科（超精密运动平台、晶圆传输系统）。
- 浸液系统：启尔机电（关键技术突破）。
- 加热带与温控：京仪自动化（已批量导入国内主流晶圆厂）。

**气体/液体/真空系统类**
- 气柜模组：国际超科林、Edwards、MKS主导高端；国内正帆科技（子公司鸿舸半导体）、至纯科技（子公司至纯集成）、富创精密（已通过泛林半导体认证）。
- 阀门：瑞士VAT全球市占率第一，派克、富士金占剩余高端；国内新莱应材（半导体级球阀，国产替代率约15%，用于中微公司刻蚀机）、北京中科艾尔、四川九天真空。
- 气体喷淋头：京瓷、CoorsTek领先；国内富创精密、华卓精科布局陶瓷件加工。
- 液体输送：Horiba、MKS垄断，国产化率不足10%；北方华创旗下七星流量计处替代初期。
- 泵：Edwards、Ebara、普旭主导；国内沈阳科仪（干式真空泵）、汉钟精机（三大核心真空泵系列，已进入国内多家头部晶圆厂）。

**仪器仪表类**
万业企业收购全球领先气体输送系统供应商 Compart System，切入高纯气体高精度零部件；北方华创旗下七星流量计等。

**光学系统类**
蔡司、尼康、佳能、Newport、Jenoptik、徕卡合计占超70%份额。国内参与厂商：北京国望光学、长春国科精密光学、茂莱光学、波长光电、科益虹源、福晶科技、福光。
新趋势：2026年AI算力带动先进封装迭代，行业走向"**以方代圆**"，CoPoS面板级封装（矩形面板取代晶圆）快速落地，带动光刻、曝光、量测类光学零部件新增需求。

**射频电源（重点品类）**
产生固定频率正弦波的高频电源，由射频信号源、射频功率放大器、阻抗匹配器组成，是等离子体配套核心电源，用于刻蚀与沉积设备。英杰电气产品覆盖13.56MHz–60MHz，可匹配中微公司CCP刻蚀机；恒运昌聚焦半导体专用电源；另有华丞电子、吉兆源、神州半导体布局。

**陶瓷件**
静电吸盘通过静电吸附力固定晶圆，减少损伤、提高精度；美日厂商主导，国内北京华卓精科、广东海拓创新已量产商业化。

> 据行行查2026年数据，大陆晶圆厂采购零部件中金额占比较大的品类还包括射频电源及各类泵，占比均在10%及以上。
